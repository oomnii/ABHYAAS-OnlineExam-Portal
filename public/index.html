About the Portal

Built for simple online exams with Clear Ownership

Teachers can create quizzes, add questions, publish or close exams, and inspect ranked attempts. Students can attempt pre-saved practice subjects or teacher-created quizzes, view answer review, and track their own performance only.

Core highlights

Everything is connected end to end.

🧑‍🏫

Teacher-first control

Create quizzes, add questions, set timer, marks, instructions, and control publish status.

🧑‍🎓

Student exam flow

Attempt pre-saved subject quizzes or published teacher quizzes with progress tracking and question palette.

📊

Result dashboards

Score, percentage, grade, subject-wise view, time taken, and answer review for every submission.

🔀

Shuffle engine

Questions and options are randomized per attempt and preserved throughout the active session.

💾

Autosave + resume

Refresh-safe attempts save current answers, timer, question index, and warning counts.

🏁

Ranked leaderboard

Fair competition per quiz using score, percentage, and lower time taken as the ranking order.

Getting Started

Try ABHYAAS with Demo Accounts

Quick Start Steps

  1. Choose a demo role below or create your own account.
  2. Teachers: Create a quiz, add questions, and click "Publish".
  3. Students: Look for "Available Quizzes" to start an attempt.
  4. Explore result analytics and leaderboards after submission!
